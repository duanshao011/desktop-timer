# 桌面计时器

一个轻量桌面小工具，用来记录每件事实际花了多久。界面是无边框闹钟形态，任务结束后会从闹钟下方吐出一段收银小票样式的记录。

## 启动方式

在项目目录运行：

```powershell
python -m src.desktop_timer
```

## 使用流程

1. 在闹钟里的输入框输入任务内容。
2. 点击输入框右侧的 `✓`，开始计时。
3. 任务中途可以点击 `暂停`，暂停后可以点击 `继续`。
4. 任务结束后点击 `终止`。
5. 闹钟下方会吐出一段小票记录，最新任务排在最上方。
6. 点击 `清除` 可以清空小票。
7. 拖动闹钟本体可以移动窗口，右上角按钮可以最小化或关闭。

## 小票格式

每条小票记录包含：

- 启动时间
- 用时
- 任务名称

第一版小票只在当前窗口运行期间保留，关闭工具后不会保存历史。
